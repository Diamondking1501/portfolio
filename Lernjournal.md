## 25.08.2026 – Git und GitHub

Wir haben Git als Versionskontrollsystem kennengelernt und den Unterschied zwischen Git und GitHub angeschaut.

Ich habe dabei unter anderem diese Befehle verwendet:

```bash
git status
git add
git commit
git log
```

Besonders wichtig war für mich der Weg einer Änderung:

**Arbeitsverzeichnis → Staging-Bereich → Repository**

Mit `git status` kann ich sehen, was gerade geändert wurde. Mit `git add` kommt eine Änderung in den Staging-Bereich und mit `git commit` wird sie als neuer Versionsstand gespeichert.

Ich habe auch gelernt, dass Git lokal funktioniert und GitHub hauptsächlich für die Online-Zusammenarbeit und das Speichern von Repositories verwendet wird.
