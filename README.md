Ich habe unter anderem mit diesen Git-Befehlen gearbeitet:

```bash

```

Danach habe ich mich mit dem **GitHub-Flow** und **Markdown** beschäftigt. Dabei habe ich gelernt, wie man mit Issues, Branches, Commits und Pull Requests arbeitet und wie man Markdown für übersichtliche Dokumentationen verwendet.

## Markdown-Beispiel

Markdown ermöglicht es, Texte einfach und übersichtlich zu formatieren.

```markdown
# Überschrift

Das ist **fetter Text**.

- Erster Punkt
- Zweiter Punkt
```
